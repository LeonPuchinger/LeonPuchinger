# About me

Hi, my name is Leon!
I'm a Software Developer based out of Regensburg (BY) focusing on languages, software architecture, developer tooling, and application development.
These are some of my publicly-available projects i've been working on:

## Languages & Compilers

- [Rouge](https://github.com/LeonPuchinger/rouge): An easy-to-learn educational programming language
- [PTIP-FFI](https://github.com/LeonPuchinger/ptip-ffi): A polyglot & transparent foreign function interface that works regardless of the memory-management-strategy involved
- [My First Compiler](https://github.com/LeonPuchinger/first_compiler) See where i came from in terms of building languages

## Application Development

- [Rouge Studio](https://github.com/LeonPuchinger/rouge-studio): The web-based development environment for the [Rouge](https://github.com/LeonPuchinger/rouge) programming language
- [Jackie Notes](https://github.com/LeonPuchinger/jackie_notes): A cross-platform handwritten note-taking app written in Flutter
- [PaceMap](https://github.com/LeonPuchinger/pacemap): An offline app for live-tracking endurance athletes on a map using GPX data

## Technical Writing

- [Rouge Docs](https://github.com/LeonPuchinger/rouge-docs): The documentation for the [Rouge](https://github.com/LeonPuchinger/rouge) programming language, separated into versions for beginners, experienced developers, and contributors
